# Aline faz 24 ♡

Álbum em HTML/CSS/JS para o aniversário de Aline. Abra dist/index.html por um servidor HTTP. As surpresas se abrem automaticamente nas datas de 28/10 a 02/11/2026, à meia-noite de São Paulo. A quinta-feira não tem evento. O bloqueio é uma experiência visual pelo relógio do dispositivo; os detalhes estão no JavaScript e não são um mecanismo de sigilo. Não há analytics nem armazenamento de dados da visitante.

Para editar mensagens e datas: dist/calendar.mjs. Fotos: dist/assets. O Sites é inicialmente privado para o proprietário; compartilhar com Aline exige configurar o acesso.
